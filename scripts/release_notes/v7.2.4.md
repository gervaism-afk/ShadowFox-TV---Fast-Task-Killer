Faster System Scan, RAM Booster, Cache Cleaner, Smart Optimize, and Stream.

- Each dashboard action performs its own job. System Scan checks running eligible apps, RAM Booster requests app cleanup, and Cache Cleaner clears eligible cache contents.
- Root discovery uses a shared five-second probe budget and remembers the working shell variant. Failed cleanup commands return their result immediately.
- Process detection uses a single system process report with a compatibility fallback. Smart Optimize reuses its package list for cache cleanup.
- Cleanup shell work has a shared time budget. Partial results and unavailable process verification are reported, and action buttons recover after failures.
- Standard mode clears ShadowFox's own cache. Supported rooted devices can also clear eligible third-party caches while respecting protected apps.
- Google TV Streamer continues to use standard mode. Other devices retain root detection.
